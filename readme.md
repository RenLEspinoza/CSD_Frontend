# Carnet Salud Digital — Frontend 🐾

Interfaz web y vista móvil pública para **Carnet Salud Digital**, orientada a clínicas veterinarias y tutores de mascotas.

## Características Principales

- **Panel Veterinario:** Gestión de pacientes (CRUD completo), subida y vista previa de fotografías, búsqueda en tiempo real, generación/descarga de códigos QR y administración de historial clínico.
- **Carnet Público QR:** Vista móvil de solo lectura al escanear el QR de la mascota, con credencial fotográfica, cálculo automático de edad, contacto directo con el tutor (llamada y WhatsApp) y línea de tiempo de vacunas y controles.

## Stack Tecnológico

- **Core:** Vanilla JavaScript (ES6+ Modules)
- **Bundler:** Vite
- **Estilos:** Tailwind CSS
